# Эволюция клетки

Небольшая браузерная игра на Canvas: игрок управляет клеткой, ест клетки меньшего размера, получает опыт и выбирает эволюции.

## Правила

- Игрок начинает маленькой клеткой.
- Клетки меньше игрока можно съесть и получить опыт.
- Клетки больше игрока опасны и могут завершить игру.
- Каждые 10 очков опыта открывается выбор эволюции.
- Всего доступно 10 эволюций.
- При каждом выборе показываются до 3 случайных вариантов из ещё не выбранных эволюций.
- Выбранные эволюции больше не появляются в следующих выборах.

Откройте `index.html` в браузере или через локальный статический сервер.
